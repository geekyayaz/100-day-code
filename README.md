## Hi, I'm Ayaz

I am an aspiring data scientist and machine learning engineer learning in public. This repository documents my 100-day coding challenge: the exercises I complete, the concepts I study, the projects I improve, and the lessons I learn along the way.

I am not trying to master every area of technology in 100 days. I am building reliable habits, strengthening the foundations that matter for internships, and creating visible evidence of steady work.

## Why this challenge?

My goals for these 100 days are to:

- Build a consistent public learning habit;
- Strengthen Python, SQL, data analysis, statistics, and machine learning fundamentals;
- Continue JavaScript through [freeCodeCamp](https://www.freecodecamp.org/);
- Solve one [LeetCode](https://leetcode.com/) problem each day;
- Build or improve portfolio projects and document them properly;
- Explain one technical or ML concept in English each week; and
- Prepare for data science, ML, deep-learning, and Python/software internships.

## Learning tracks

### Primary track: Data and Machine Learning

The main focus is Python, NumPy, pandas, data visualization, SQL, statistics, classical machine learning, and the foundations needed to move into deep learning and practical ML systems. Portfolio projects will turn those skills into evidence.

### Secondary tracks

- **JavaScript** 
- **LeetCode**

## 100-day roadmap

This is a direction, not a rigid syllabus. I will adjust the pace when a topic needs more time.

| Phase | Days | Direction |
| --- | ---: | --- |
| **1. Build the system** | 1–20 | Establish the routine; reinforce programming, Git, Python, SQL, and problem-solving basics. |
| **2. Work with data** | 21–40 | Practise NumPy, pandas, data cleaning, exploratory analysis, visualization, and core statistics. |
| **3. Learn ML fundamentals** | 41–60 | Study supervised and unsupervised learning, evaluation, feature work, and reproducible experiments. |
| **4. Build portfolio evidence** | 61–80 | Create or improve end-to-end projects; strengthen documentation, testing, deployment, and presentation. |
| **5. Consolidate and prepare** | 81–100 | Revisit weak areas, explore selected advanced topics, polish the portfolio, and practise internship-ready communication. |

Deep learning, PyTorch, MLOps, LLMs, RAG, agents, DSA, and web/software development are long-term directions. During this challenge I may explore some of them, but only after protecting the fundamentals and the core daily system.

## Repository structure

The repository will evolve with the challenge. I will add folders only when there is real work to put in them.

```text
100-day-code/
├── JS/                   # JavaScript exercises and notes
├── Python/               # Python practice and small programs
├── SQL/                  # Queries, schemas, and exercises
├── Data-Analysis/        # NumPy, pandas, visualization, and EDA
├── ML/                   # Statistics and machine-learning experiments
├── LeetCode/             # Daily problem-solving notes or solutions
├── Projects/             # Portfolio projects and case studies
├── Weekly-Summaries/     # Reviews and English concept explanations
└── README.md
```

At the start of the challenge, only the folders backed by completed work may exist.
